# LeetVerse Frontend (SPA)

This directory is reserved for the LeetVerse React frontend application (Vite + React + TypeScript + Tailwind/CSS).
It will be implemented in the next phase.

### Planned Key Surfaces:
- **Public Website:**
  - `/` (Home, stats, highlights)
  - `/domains` / `/team` (Domain-based member browser with cached blob)
  - `/projects` (Project showcase & member credits)
  - `/gallery` (Events grid with live popup images fetch)
  - `/u/:username` (Live digital business card)
- **Admin Panel:**
  - `/admin/login` (Google OAuth authentication)
  - `/admin` (Tree-view domain & member manager with per-field autosave, project editor, gallery editor)
